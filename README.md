
## Summary

An alternate Pebble-HF QRP radio firmware

NOTE: This is experimental firmware and it is not endorsed by or supported by the Pebble developers.
To receive support for your Pebble radio you should use the official firmware wich is available here:
https://github.com/mspiceland/usdx-pebblehf

## Description

The original uSDX 1.02w firmware was written by Guido (PE1NNZ)
https://github.com/threeme3/usdx

The uSDX 4.00e firmware is a branch of the original uSDX firmware by Rob (GW8RDI)
https://github.com/GW8RDI/uSDXOpen

This alternate Pebble-HF firmware is derived from the uSDX 4.00e firmware.
